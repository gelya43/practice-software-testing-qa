# Practice Software Testing – QA Portfolio

End-to-end QA portfolio project based on the Practice Software Testing web application.

This project demonstrates the complete manual testing workflow from requirements analysis and test design to test execution, defect reporting, and requirements traceability.

## Project Overview

The application was tested across 5 functional sprints using Jira and Zephyr.

### Testing Results

- 5 functional sprints completed
- 166 test cases designed
- 157 test executions completed
- 151 tests passed
- 3 tests failed
- 3 tests blocked
- 3 defects reported

## Tools

- Jira – requirements and defect management
- Zephyr – test case management, execution, and traceability
- Chrome DevTools – testing and investigation
- GitHub – project documentation
- Playwright – test automation (in progress)
- JavaScript – automation language
  
## Test Scope

Functional testing covered the main user and administrative workflows of the application, including:

- Product browsing and product details
- Categories, brands, filters, and search
- Shopping cart and quantity management
- Checkout, billing, and payment
- User registration and authentication
- Favorites
- Rental products
- Contact form and file validation
- Multi-language functionality
- Location-based and combination discounts
- Chat functionality
- Admin product, category, brand, order, user, message, and report management
- Privacy Policy
